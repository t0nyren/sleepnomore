# 西游记白话睡前版 · 写作规范

100 回。整体规范跟三国/水浒系列一致（看 `presets/sanguo/STYLE.md`），本文只列西游特有的差别。

## 1. 神话氛围放在第一位

跟三国/水浒不同，西游是神话。每一回里会出现：神仙、妖怪、法宝、变化、咒语。睡前故事要做的不是渲染惊险，而是把这些奇幻元素写成**梦一样的画面**——像在云里、在烟里、在远远的山顶看到的影子。

- 写"忽然一阵风过，山头上出现一位身穿黄衫的老人"，不写"一道金光照亮夜空，雷霆撕裂大地"
- 法宝出场轻轻描摹一笔（一只葫芦、一柄拂尘、一条丝绦），不要列清单
- 变化（孙悟空 72 变）：一句话交代结果，不渲染过程

## 2. 妖魔斗法 = 三国战阵 = 一笔带过

- "孙悟空挥棒打去，那妖怪招架不住，化作一阵黑烟逃走了。" 是好的写法
- 不写血肉、不写惨叫
- 妖怪现原形、被收伏、回归山林——用画面收尾，不用渲染暴力

## 3. 主要人物画面（首次出现统一这样写）

| 人物 | 第一次出现时的一笔画面 |
|---|---|
| 孙悟空 | 毛脸雷公嘴，一双火眼金睛，行动如风。 |
| 唐僧 | 眉清目秀，骑一匹白马，神情温和而坚定。 |
| 猪八戒 | 长嘴大耳，肚子圆滚，肩上扛一柄九齿钉钯。 |
| 沙僧 | 脸色青黑，颈上挂一串骷髅念珠，话不多。 |
| 白龙马 | 通身雪白，鬃毛微微抖动。 |
| 观音 | 头戴金箍，手持净瓶，足下一朵白莲。 |
| 太上老君 | 须发雪白，骑一头青牛。 |
| 玉皇大帝 | 端坐凌霄宝殿，面容温和不怒。 |

后续出现直接用名字，不重复描写。

## 4. 妖怪的"原形"

每一回的妖怪几乎都有原形（蜘蛛精/老鼠精/狮子精/蝎子精等）。**直接告诉听众它的原形**——西游的读者文化里这是日常知识，不要写成悬念。

> "那妖怪原是黑熊修炼成精，已在山中住了几百年。"

不写"那妖怪究竟是何方神圣，下回分解"这种悬念钩。

## 5. 道家术语和心性比喻

原著大量用"心猿""意马""木母""金公""婴儿""姹女""黄婆"等内丹术语。**全部翻译成现代白话**：

- "心猿"= 孙悟空（直接用名字）
- "意马"= 白龙马（直接用名字）
- "木母""金公"= 猪八戒、孙悟空（用名字）
- 心性议论（如第 7 回结尾的偈语）：改成两三句白话总结，不照搬

## 6. 佛教典故的处理

观音、如来、各位菩萨出场可以保留。**但不照搬经文**：

- 不出现梵文、不出现"摩诃般若波罗蜜"这类
- "心经"等典故一句话带过："唐僧学了一卷心经，从此心里多了一份安稳。"
- 不渲染宗派之争、不讨论佛理深浅

## 7. 取经队伍的关系

四师徒 + 白马的相处是西游的灵魂。在斗妖之外，多写他们在路上的小细节：

- 八戒嘴馋偷懒
- 沙僧默默挑担
- 悟空机敏调侃
- 唐僧念紧箍咒

这些日常画面比打斗更让听众放松。一回里至少一处。

## 8. 取经路上的"地理"

西游的地理是虚构的："乌鸡国""车迟国""女儿国""狮驼国"……不要混进真实历史地理（不写"长安在陕西"，但可以说"出了长安一路往西")。

## 9. 收尾意象（西游池）

- 一朵祥云远去
- 师徒四人在月下走入山林
- 山门口的香烟袅袅
- 远处一声梵唱
- 白马的蹄声慢慢消失
- 一片落叶（落樱）
- 远处的水

不准跨集模板段落，按三国 §7 严格要求。

## 10. 整体走向

西游可以分成几段：

- **ch.1-7**：孙悟空学艺 + 大闹天宫
- **ch.8-12**：唐僧出世 + 取经缘起
- **ch.13-100**：取经路上九九八十一难

每集（除前 7 回）大体一个独立故事：到一个地方 → 遇妖 → 收伏 → 上路。节奏要稳，不必每集都"九死一生"。

## 11. 参考样本

第 1 回 `001.json` 是参照样本。新写的回目应当跟它在节奏、视角、安抚 cue 上对得上。
