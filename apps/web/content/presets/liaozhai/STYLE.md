# 聊斋志异白话睡前版 · 写作规范

蒲松龄《聊斋志异》四百余篇中精选八十篇（见 `_toc.json`）。整体规范同三言系列（先读 `presets/yushiming/STYLE.md` 与 `presets/sanguo/STYLE.md`），本文只列聊斋特有的差别。**每篇一个独立故事，互不连缀**，每篇要在本集内把人物、来龙去脉交代完整。

## 1. 基调：文白参半 · 夜读古宅 · 半梦半醒

聊斋原文是文言短篇，画面感极强、含蓄隽永。睡前版的命脉是 **"半梦半醒的夜读感"**：

- **文白参半**，不做完全直译——句子用白话讲清楚，但保留蒲松龄那一点含蓄、那一点留白的味道，不要把话说尽、说白、说俗。
- **以"夜读书生 + 古宅幽梦"为整本主氛**：荒寺、古宅、空斋、深巷、夜雨、青灯、旧屏风——把读者带进一个安静、微凉、似真似幻的夜晚。
- 节奏比情节重要。是"夜里讲一个轻轻的怪谈"，不是说书抖包袱，更不是恐怖故事。

## 2. 聊斋写法精髓：重"之前的孤寂"与"之后的怅惘"

这是聊斋区别于三言的关键，也是它最助眠的地方：

- 奇遇本身往往简短——一次相逢、一段情缘、一桩异事，**不必铺张**。
- 重头放在 **"奇遇之前的孤寂"** 和 **"奇遇之后的怅惘"**：
  - 一切都未发生时的 **夜灯下、空斋中**——独居的书生、寂寂的庭院、远处的更声。
  - 一切都已过去时的 **空院子、旧物件**——人去楼空、花影依旧、怅然若失。
- 这"一头一尾的静"，撑起整篇的呼吸。中间的奇遇，是镶在这片夜色里的一点微光。

## 3. 入话与议论：删"异史氏曰"，化白话点到即止

- 蒲松龄篇末常有"异史氏曰"的大段议论评点 → **压成一两句温和的回味**，点出本篇的味道即可，不照搬、不说教。
- 正文里的诗词、判词 → 一句白话转述。
- 不出现"看官""话说""且听下回"这类说书套语。

## 4. 避坑硬清单（违者重写）

1. **房中术 / 床笫细节**：蒲松龄偶有露骨处，**全砍**。亲密一笔到"半夜灯下她替他添了一杯热酒""她回身替他掖了掖被角"这种温暖含蓄的意象即止，绝不写皮肉之欢。
2. **食人 / 剖腹 / 邪术血腥**（《尸变》《李司鉴》《菱角》等过恐篇）：选目已 skip；行文中若涉死伤、降妖，一笔带过，不血腥、不渲染恐怖。志怪的"奇"靠氛围与留白，不靠惊吓。
3. **狐女变形术**：不写"皮肉的展开/褪去"，只写"她回头一笑，背影没入花影""灯下再看，案上只余一只绣鞋"这种含蓄笔法。
4. **科举怀才不遇**：聊斋此类极多，作为整本的一缕底色可留，但**单篇都化成"考完场后的雨夜""放榜前的空斋"这种静画面**，写心境不写愤懑议论。

## 5. 人物：一笔画像，再现只用名字

聊斋人物每篇换一批。首次出场给 **一笔具象画面**（身量/面容/衣着/神气/嗓音取其一二），再次出现只用名字。狐仙花妖的"非人"之处，靠细节暗示（一缕异香、一闪即逝的背影、雪地里没有脚印），不靠直白说破。

## 6. 拆 / 合规则

- 聊斋多数单篇 1–3K 字，**扩到 2500 字目标**（硬范围 2200–3300，target 2500–2700）。
- 短小者（《种梨》《偷桃》《山市》《雨钱》等）：单写一集，**补世态人情、夜读氛围的细节**充实之，不与他篇合并。
- 超长篇（《婴宁》《聂小倩》《续黄粱》《香玉》等）：走**单集精简**，抓主线与气氛，删枝蔓，不拆成多集。

## 7. 硬规则（同三言，Tio 会查）

- body 2200–3300 硬范围 / target 2500–2700；写完 **务必确认 ≥2450 再 push**。
- 对话用全角双引号 “ ”，**绝不**用 ASCII "；无半角标点、无拉丁字母、无阿拉伯数字。
- 文件名 `NNN.json` 零填充；`originalTitle` 必须与 `_toc.json` 完全一致；`author` 统一 `Writer1@opus`。
- 暴力/死亡/情欲一笔带过。

## 8. 收尾意象池（走聊斋夜读感，跨篇不重复、last-120 字不撞模板）

青灯古卷 / 夜半敲门 / 庭前桂树 / 落雨打芭蕉 / 深巷犬吠 / 烛芯爆一声 / 朱漆门半掩 / 古衣箱 / 旧屏风山水褪色 / 空斋积尘 / 阶前苔痕 / 墙头探出的花枝 / 檐下风铃 / 晓色微明……

**避灯月做主收尾**（青灯、残月可作内文氛围，但每篇结尾的主意象要散开、求新，不连续复用同一感官）。每篇收尾留一点"怅惘而安然"的回味，让人轻轻合眼。
