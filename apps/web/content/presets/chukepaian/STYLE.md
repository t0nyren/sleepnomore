# 初刻拍案惊奇白话睡前版 · 写作规范

四十卷，凌濛初撰。整体规范跟三国/红楼系列一致（看 `presets/sanguo/STYLE.md`），本文只列「初刻拍案惊奇」特有的差别。

## 1. 偏重：一卷一个完整的奇事，但放慢说

「二拍」是话本，原本带强烈的说书腔（入话、头回、"看官听说"、卷末劝惩诗）。睡前版要把这层壳剥掉：

- **删掉入话/头回的铺垫小故事**，直接从正话主角讲起，开头一两句交代他是谁、在哪个朝代、过着什么日子即可。
- 每卷是一个**因缘际会**的故事——一次远行、一桩奇遇、一回错认、一场公案。事件本身曲折，但叙述要慢：多写一处天气、一处屋内、一段人物心里的转念。
- **节奏比情节重要**。原著一回里挤的巧合，挑主线讲清楚，枝节一笔带过。
- 卷末原有的劝惩议论、因果点题，**全删**，换成一个安静的画面落点（见 §8）。

## 2. 诗词、入话诗、劝世诗改白话或删

原著开头常引一首诗或词起兴，卷中人物也题诗。处理：

- 起兴的入话诗：**直接删**，从正话讲起。
- 卷中确属情节的诗（如题壁、传情、谶语）：改成一两句白话转述——"他在墙上留了几个字，说此别不知何年再见"。
- 不照搬一句原文格律。

## 3. 主要人物首次画像（各卷不同，首次出现给一笔具象画面）

二拍人物多是市井众生，不是名将名媛。画像要**贴身份、贴行当**，让听众一眼看见这是个什么人：

| 类型 | 首次画面举例 |
|---|---|
| 落魄书生（如文若虚） | 衣衫旧了，面目却还清秀，说话斯文，眼里带点认命的笑。 |
| 走海商人 | 皮肤晒得黑红，手掌粗厚，说话嗓门大，腰间一只磨亮的算袋。 |
| 老船家 | 背微驼，赤脚，嗓子却亮，一双眼睛看得透风看得透浪。 |
| 波斯/异邦胡商 | 须发花白而卷，鼻梁高，眼睛是浅色的，看货时手指轻轻一敲就知好坏。 |
| 市井妇人 | 鬓边一支旧银簪，手脚麻利，笑起来有两个浅浅的酒窝。 |
| 江湖侠者（如韦十一娘） | 一身利落短装，步子轻，话不多，眼神定。 |
| 清官/知县 | 面目端正，问案时不急不徐，听完才开口。 |

后续出现直接用名字，不重复描写；同一卷里同一人也只画一次。

## 4. 称呼与年代

- 人物多用**本名 + 行当/排行**称呼：文若虚、刘东山、十八兄、韦十一娘、苏小娟、崔俊臣。第一次出现把名字交代清楚。
- 朝代背景按原著（多为唐宋元，间有本朝），开头一句点明"从前"/"某朝年间"即可，不必考据。
- 银钱用汉字写："一两银子""千金""几贯钱"，不写阿拉伯数字。

## 5. 小道具（每卷至少一处有温度的器物 / 风物）

二拍最好看的是市井细节与奇货异物。每卷落一处可触可闻的东西：

- 一筐红得发亮的洞庭红橘
- 一只乌沉沉、半间屋大的旧龙壳
- 一袋磨得发亮的算珠
- 一盏渔火、一片帆影
- 一支旧银簪、一方芙蓉屏
- 客店墙角一盏将尽的油灯

不要列单，**一处就够**，但要写得让人看得见、闻得到。

## 6. 冲突 / 暴力 / 公案 一笔带过

二拍里有不少凶案、奸情、强梁、阴司报应。一律点到为止：

- 凶杀："那夜他没能回来，第二天才在水边找到人。"——不写刀、不写血、不写挣扎。
- 奸情：只交代"两人有了首尾""坏了名节"，**不写任何露骨细节**。
- 公案、阴司报应：写"过了几年，事情到底败露了""善恶各有了着落"，把因果交代清楚，不渲染酷刑、不写鬼物狰狞。
- 牢狱、刑讯：一句带过，写出转折即可。

## 7. 段落与口吻

- 第三人称、温和的床头叙述者，不抖包袱、不留"且听下回分解"。
- 每段 1–4 句，段间空一行，关键转折单独成段让 TTS 自然停顿。
- 对话用**全角双引号 " "**，绝不用 ASCII 引号；不嵌套引号；说话动词以"说""问""答"为主。
- 删尽话本套语："看官""话分两头""按下不表""有诗为证"一概不要。

## 8. 收尾意象池（卷末安静落点，每卷必须不同，严禁跨卷复用整段）

收尾锚在**本卷出现过的人/物/地**上，给一个余韵画面，不写抽象通论、不点劝惩主题：

- 太湖边又红了的一筐橘子，风里一点清香
- 海上一片远去的帆影
- 客店里一盏渐渐燃尽的油灯
- 渡口空了的一只小船
- 墙上一行旧字，被雨水洇淡
- 一支重新插回鬓边的银簪
- 衙门外散去的人群，石阶上一点残阳
- 远处更鼓一声，巷子静下来
- 江上雾起，仙书随波不见

⚠️ 严格按三国 §7：批量写时最易跌进同一段抒情模板，卷末**整段散文**都要每卷不同，QA 会跨卷 diff 倒数 150 字。

## 9. 字数与字符

- body 硬 2200–3300，软 2400–3100，**目标 2500–2700**。
- 纯简体中文 + 中文标点；body 内无拉丁字母、无阿拉伯数字、无 emoji、无 markdown。
- 生僻人名地名首次出现注拼音，如鼍龙（tuó lóng，正文尽量回避，写"大龙物"亦可）；常见字不注。

## 10. 标题字段

- `title`：我们自起的睡前短标题（白话、3–5 字，不照搬原回目），如卷一作《时来运转》。
- `originalTitle`：从 `_toc.json` 取，验证脚本会比对，须一字不差。
- `summary`：列表页用，一到两句，不剧透结局，末尾不加句号。

## 11. 整体走向 / 选材

四十卷题材庞杂，睡前版按"适合床头"程度安排笔墨：

- **奇遇致富 / 因缘巧合**（卷一、卷十八、卷二十二等）：最宜睡前，多写际遇之奇与人物的从容。
- **侠义 / 公案断狱**（卷三、卷四、卷十一、卷十三、卷三十三等）：写清来龙去脉，凶处一笔带过，落在"水落石出"的安定感上。
- **婚姻错认 / 悲欢离合**（卷二、卷九、卷十、卷二十三、卷二十七等）：偏暖，写久别重逢的安心。
- **神道因果 / 仙踪异事**（卷七、卷二十八、卷三十九、卷四十等）：保留"远远看像一场梦"的距离感，只写画面不写道家术语。
- **奸盗凶杀类**（卷六、卷三十二、卷三十六等）：题材偏重，务必淡化，重在因果了结的安定，不渲染。

## 12. 参考样本

第 1 回 `001.json`《时来运转》（转运汉遇巧洞庭红）是参照样本：开篇直入正话、文若虚的认命与转运、海外卖橘、荒岛拾壳、波斯胡识宝、卷末太湖橘香的落点——新写各卷应当跟它在节奏、视角、收尾 cue 上无缝拼接。
