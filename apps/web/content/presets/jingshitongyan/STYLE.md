# 警世通言白话睡前版 · 写作规范

四十卷，冯梦龙编。整体规范跟三国/红楼系列一致（先看 `presets/sanguo/STYLE.md` 的篇幅、视角、战斗一笔带过、章末安抚 cue、字符规范），本文只列 **警世通言特有** 的差别。

> ⚠️ 引号硬规则（本系列）：`body` 里所有对话/引文一律用 **全角弯双引号 “ ”**（U+201C / U+201D），**绝不用 ASCII `"`**。

## 1. 偏重：一卷一个独立故事，重"离合悲欢"不重宏大叙事

警世通言是话本短篇集，**每一卷就是一个完整的故事**，卷与卷之间没有连续情节。睡前改写时：

- 每回自成起讫，开头交代人物、地点、时节，结尾把这一个故事收圆，不留"下回"钩子
- 题材以 **市井人情、夫妻离合、知音情义、因果报应** 为主（俞伯牙与钟子期、杜十娘、白娘子、玉堂春……）
- "通言"是劝世的口吻，但改写时 **把说教化进故事**，不要在正文里跳出来讲大道理；原话本常有的入话诗、篇末"奉劝世人"几句，一律删掉或化成一句淡淡的余韵
- 节奏比情节重要：商旅、客船、酒楼、绣房、寺观这类话本场景，多写一两笔氛围

## 2. 诗词、入话、判词 → 两三句白话

话本里大量的开篇诗、词、酒令、书信、判词：

- 开篇"入话"小故事和定场诗 → 直接删掉，从正文主故事讲起
- 人物吟的诗、写的信 → 化成一两句白话转述（"他在墙上题了一首诗，大意是说……"）
- 不照搬一句原文古诗；原诗的意境改成画面或心情即可

## 3. 主要人物首次画像（首次出现统一这样写，各卷人物各异）

每卷人物不同，第一次出场给 **一笔具象画面**（身材／面容／神态／一件随身物），后续直接用名字、不再描写。参考基调：

| 人物 | 第一次出现时的一笔画面 |
|---|---|
| 俞伯牙（ch.1） | 一身素净的大夫装束，神色清冷，怀里一张瑶琴。 |
| 钟子期（ch.1） | 青年樵夫，肩上一担柴，手里一柄斧，草鞋沾泥，眉目清朗。 |
| 杜十娘（ch.32） | 京城名妓，眉如远山，眼如秋水，神态里却有一段说不出的郑重。 |
| 白娘子（ch.28） | 一身素白，眉目温柔，撑一把油纸伞立在雨里。 |
| 玉堂春（ch.24） | 容貌清丽，一双泪眼，落难中仍是端然的样子。 |

> 写到自己负责的卷时，按这一卷主角的身份临时定一笔画像即可，**不要套用别卷的模板**。

## 4. 称呼与时代

- 多用话本里的市井称呼：相公、官人、娘子、员外、客官、舍人、待诏、解元
- 保留少量"话说""原来""那"作调味，但不堆砌；不出现"看官""且听下回分解""按下不表"
- 朝代背景按各卷原著（多为宋元明），地名人名照原著，生僻字第一次出现附拼音

## 5. 小道具（每回至少一处，让场景有温度）

警世通言的故事多落在市井，器物细节最能立住画面，**每回至少一处**：

- 一张瑶琴、一炉香、一盏船头的小灯
- 一只描金的百宝箱、一封压在枕下的书信
- 一把油纸伞、一碗客栈的热汤、一串当票
- 一枝当作信物的钗、一面破镜

不堆砌清单，**一处写透**即可。

## 6. 冲突／死亡 = 一笔带过

话本里不乏官司、负心、投江、雷殛、报应的场面。一律 **点到为止**：

- 负心、骗局：写结果和人物的心境，不渲染恶毒细节
- 死亡（投江、病故、雷殛）：用"沉了下去""一病不起""不再起来"这种轻笔，写成一种安静的告别，不写痛苦、不写血
- 公案里的刑讯、报应里的惨状：略写或转述，不给画面

## 7. 段落与对话

- 每段 1–4 句，段间空行，关键转折单独成段
- 对话用全角弯双引号 “ ”，不嵌套；说话动词以"说／道／问／答"为主，不堆砌
- 句号优于逗号，多用短句

## 8. 收尾意象池（按卷轮换，严禁跨卷复用整段）

每卷结尾留一个 **安静、锚在本卷剧情上** 的画面，句式逐卷变化，**绝不每卷都"愿你做一个好梦"**：

- 江风吹低了坟头的草
- 船灯在水面上晃了一晃，渐渐远了
- 一把伞收起来，雨还在下
- 绣房里的灯，半夜里熄了
- 客栈的门虚掩着，街上一个人也没有
- 一枝钗静静躺在妆台上
- 江上的雾慢慢合拢，看不见来路
- 寺里的钟声响过一遍，山就静了

⚠️ 严禁跨卷模板段落：结尾整段散文每卷都要不同，QA 会跨卷 diff 倒数 150 字。

## 9. 整体走向（四十卷无主线，按题材松散分布）

警世通言四十卷各自独立，没有贯穿主线。改写时只需保证：

- 每卷自成一个完整短篇
- 全系列保持同一把"睡前嗓子"——温和、缓慢、留白
- 名篇（ch.1 知音、ch.24 玉堂春、ch.28 白娘子、ch.32 杜十娘）尤其要稳，是系列的门面

## 10. 参考样本

第 1 回 `001.json`《摔琴谢知音》是参照样本。开篇江口夜泊的氛围、伯牙子期对答的节奏、结尾"江风吹低江边草"的安抚 cue——这些是基准，新写的卷应当能跟它无缝拼接。
