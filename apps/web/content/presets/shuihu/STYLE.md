# 水浒传白话睡前版 · 写作规范

这是面向 SleepNoMore（眠安）app 的预设故事内容。读者是临睡前的听众，音频由 TTS 朗读，听者会在故事中段或末尾入睡。所有 100 回必须保持同一种声音、同一种节奏。**整体规范跟三国系列一致**，本文只列水浒特有的差别。

## 0. 基线沿用三国

字数、视角、段落、对话、章末安抚、字符与拼音、不允许内容、文件格式、工作流——全部沿用 `presets/sanguo/STYLE.md`。下面只补水浒特别注意点。

## 1. 江湖暴力的软化是水浒的核心难点

水浒比三国的暴力**更日常、更近距离**：拳打、棒杀、剥人皮、血溅鸳鸯楼。原著相当多场景如直译就违反睡前规范。**必须改写**：

- **拳脚相搏**："鲁智深三拳打死镇关西"——改为"鲁智深一拳打去，镇关西倒下，再也没起来。" 不写血肉模糊。
- **刀斧场面**：用"刀光一闪""倒下"取代具体伤口。
- **凌迟、剐刑、剥皮**：直接略过，只交代结果——"那贼受刑而死"，不写过程。
- **武松血溅鸳鸯楼**这一类：交代他动手了、人死了、墙上有字，**不写连杀十数人的画面**。
- **景阳冈打虎**：可以写老虎"扑过来"、武松"打下去"，节奏要快不要慢；不写虎被打烂的细节。

## 2. 大碗酒 / 大块肉

水浒的好汉以**吃喝**立人物。这部分**可以保留**，是放松感的来源：

- 写"一碗酒下肚""撕了一只熟鸡"是好的画面词
- 但不要列菜单、不要堆砌"羊肉牛肉鹿肉野味狼肉"
- 一两句到位

## 3. 江湖称号与绰号

每个好汉都有绰号（鲁智深"花和尚"、武松"行者"、李逵"黑旋风"等）。第一次出现时，**正式名 + 绰号 + 一笔画面** 同时给：

> "他姓鲁名达，因为后来做了和尚又满身花绣，江湖上叫他花和尚鲁智深。这人身材壮实，嗓门极大，平日里最看不得有人欺负弱小。"

后续直接用名字或绰号都行，但同一回里**只挑一种**保持一致，不要混用。

## 4. 女性人物

水浒原著对女性角色相当不友好（潘金莲、阎婆惜、扈三娘、孙二娘等）。在改写时：

- 不照搬"淫妇""泼妇"这类道德标签
- 对潘金莲、阎婆惜的情节，**写发生了什么**（毒杀、私会、被杀），**不写道德审判**
- 扈三娘、孙二娘、顾大嫂这种女将，正常给画面、给绰号，跟其他好汉一样平等待

## 5. 称号读音

水浒里有些字读音特殊，第一次出现时附拼音：

- 呼延灼（hū yán zhuó）
- 卢俊义（lú jùn yì）—— 不需要，"俊义"两字常见
- 阮小七（ruǎn xiǎo qī）—— 阮姓注一次
- 戴宗（dài zōng）—— 不需要
- 燕青（yān qīng）—— 燕字此处读阴平
- 没遮拦穆弘、没羽箭张清的"没"字 —— 此处读 méi 不是 mò

常用名（鲁智深、林冲、武松、宋江、李逵、晁盖）不需注音。

## 6. 地名

宋朝地名跟现代地名差异大。第一次出现时如读法易错可附拼音：

- 沧州（cāng zhōu）
- 郓城（yùn chéng）
- 阳谷县（yáng gǔ xiàn）—— 不需要
- 浔阳江（xún yáng jiāng）
- 揭阳岭（jiē yáng lǐng）

## 7. 标题（自起的短标题）

跟三国一致，4–8 字，睡前友好。例如：
- ch.1：洪太尉走妖魔
- ch.3：鲁达拳打郑屠
- ch.10：风雪山神庙
- ch.16：智取生辰纲
- ch.23：景阳冈打虎
- ch.70：忠义堂排座次

## 8. 收尾意象（水浒池）

水浒的画面词比三国更"草莽" + "市井"。结尾意象可以从这一池子里挑（同样不准跨集重复整段）：

- 风雪 / 雪夜 / 草垛
- 客栈灯笼 / 酒旗
- 江岸 / 渡船 / 芦苇
- 月光下的山路
- 鼓楼更声 / 街口的灯
- 庙门口的香火
- 马蹄声远去

仍然遵守三国版 §7：每集结尾画面不同 + 没有跨集模板段落。

## 9. 整体走向（写作时心里要有一条线）

水浒一百回大致可以分四段：

- **ch.1-40**：单线英雄列传——鲁智深 / 林冲 / 武松 / 杨志 / 宋江 各自的故事，互相还没真正聚到一起
- **ch.41-70**：上梁山 + 集体战斗，三打祝家庄、攻城拔寨，到 70 回排座次定型
- **ch.71-82**：受招安过程
- **ch.83-100**：奉诏征辽（如 100 回本含征辽部分；后面征方腊在 120 回本）

写作时要让节奏跟着这个走向变化：前 40 回是"个人故事 + 江湖风物"，后段是"集体行动 + 战阵"。
