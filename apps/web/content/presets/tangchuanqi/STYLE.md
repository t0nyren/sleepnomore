# 唐传奇白话睡前版 · 写作规范

唐代文言短篇小说（传奇）精选，共 42 集。整体规范跟三国/警世通言系列一致（先看 `presets/sanguo/STYLE.md` 的篇幅、视角、战斗一笔带过、章末安抚 cue、字符规范；本系列的节奏/字数/避坑沿用我在 `jingshitongyan` 练熟的那一套），本文只列 **唐传奇特有** 的差别。

> ⚠️ 引号硬规则（本系列）：`body` 里所有对话/引文一律用 **全角弯双引号 “ ”**（U+201C / U+201D），**绝不用 ASCII `"`**（会破坏 JSON）。

## 0. 字符 / 篇幅硬规则（与前序系列一致）

- `body` 纯中文：**零 ASCII 引号、零拉丁字母、零阿拉伯数字、零半角标点**；全角引号必须配平。
- 篇幅：硬性 2200–3300，目标 **2500–2700**（软下限 2400）。
- 文件名严格 `NNN.json`（`001.json` 不是 `1.json`）。
- `author` = `Writer2@opus`；`createdAt` ISO 8601 UTC。
- `originalTitle` 必须与 `_toc.json` 完全一致（拆集用 `（上）/（下）` 区分）。
- 跨集结尾不复用整段（QA 跨集 diff 倒数 ~150 字，last-150 jaccard 控在 0.45 以下）。

## 1. 基调：文白参半的唐风 + 含蓄 + 助眠静画面

唐传奇是文言短篇，比明清话本更典雅、更讲意境。改写时：

- **文白参半**：不照搬原文骈俪，但保留几分唐人的清雅古意——句子可略长、用词略文，避免过分口语化的市井腔（不要写成话本里"那员外道"的味道）。
- **每集自成起讫**：开头交代人物、时节、地点，结尾把故事收圆，不留钩子。
- **重画面、重氛围、轻情节张力**：唐传奇的灵魂是"画面感"和"梦境的真实感"。多写洞庭烟波、长安暮色、客店灯火、屋脊夜行这类静景；冲突点到为止。
- **含蓄**：所有亲密细节 **全砍**，重点放在"等候"与"分别"的静画面（一个人倚门、一封未拆的信、一盏将尽的酒）。说教、原文的"赞曰/论曰"一律删掉，化成一句淡淡余韵。
- 原诗词、书信、判词 → 化成一两句白话转述，**不照搬原文古诗**；原诗意境改成画面或心情。

## 2. 五大题材分类（42 集分布）

1. **龙宫幻梦 / 仙缘**（1-12）：柳毅传(2)、枕中记、南柯太守传(2)、离魂记、杜子春、任氏传、古镜记、裴航、文箫吴彩鸾、封陟。**核心：梦境的真实感 + 醒来后的空座感**——这是 perfect 助眠题，黄粱/南柯醒来那一刻要写足"恍如隔世、四下空寂"。
2. **市井痴情（香艳但克制）**（13-20）：李娃传(2)、霍小玉传、莺莺传、步飞烟传、柳氏传、崔护觅水、长恨歌传。亲密全砍，重"等候/分别"。
3. **侠义夜行**（21-24）：聂隐娘、红线传、昆仑奴、虬髯客传。打斗一笔带过，重点在 **夜行、屋脊飞跃、凌晨的雾**。
4. **公案义烈**（25-27）：谢小娥传（字谜复仇）、无双传（古押衙义救）、吴保安（弃家赎友）。复仇/死亡含蓄写。
5. **神怪幻梦 + 笔记压轴**（28-42）：郭元振、孙恪、张老、崔玄微、杜兰香、板桥三娘子、三梦记、樱桃青衣、秦梦记、湘中怨解、东阳夜怪录、东城老父传，开元天宝遗事(2)、太平广记拾遗（压轴合集，散点盛唐遗事/灵异/神仙，给整部书一个开阔收束）。

## 6. 避坑清单（coordinator 指令，务必记牢）

- **亲密细节全砍**：李娃/霍小玉/莺莺/步飞烟/任氏的情爱场景，只写情意与等候分别，绝不写身体细节。
- **死亡血腥一笔带过**：霍小玉传的"鸳鸯誓约"与最后含恨而终、化厉鬼报复的场景 **克制带过、千万别详写**；谢小娥的杀父杀夫之仇、复仇手刃，皆一笔。
- **打斗刀光不重描**：聂隐娘/红线/昆仑奴/虬髯客的厮杀、行刺、空中相斗，只取"夜行/飞跃/雾/剑光一闪"的画面，不血腥。
- **政治派系倾轧略写**：长恨歌传的安史之乱、马嵬之变只作背景一笔，重在玄宗事后的追思空寂；不展开朝堂党争。
- **梦/妖/仙的超现实**：写出"真实感"即可，不渲染恐怖；东阳夜怪录、板桥三娘子（变驴之术）等取奇趣，不取惊吓。

## 7. 收尾意象池（盛唐感，按集轮换，严禁跨集复用整段）

每集结尾留一个 **安静、锚在本篇剧情上** 的画面，句式逐集变化，避开前序系列已重的 灯/月/松，盛唐意象优先：

- 洛阳花市的晨雾，一夜春深，满街花气未散
- 曲江池上的水光，画船歇了，只剩一片粼粼
- 长安城头的初雪，落在朱雀大街的青石上
- 江南雨夜，檐溜一声一声，敲到天明
- 洞庭龙宫散尽的宝光，水面合拢，只余烟波万顷
- 古槐下蚁穴的黄昏，一梦醒来，斜阳还挂在原处
- 戍楼的一缕远笛，越过陇头的暮云
- 邯郸客店灶上的黄粱，还没蒸熟
- 终南山的云气，漫过药炉，又散开
- 平康里的更鼓，一声一声，敲远了
- 蓝桥驿外的捣药声，月下（按需改），一杵一杵
- 渭城朝雨，客舍青青，柳色又新

> ⚠️ 严禁跨集模板段落：结尾整段散文每集都要不同。意象在上面这个池子里轮换，并随剧情微调。
