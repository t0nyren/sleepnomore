# 喻世明言白话睡前版 · 写作规范

四十卷（《古今小说》，冯梦龙编，今题《喻世明言》）。整体规范同三国系列（先读 `presets/sanguo/STYLE.md`），本文只列喻世明言特有的差别。**每卷一个独立故事，互不连缀**，不像三国/红楼有连续主线——所以每卷要把人物、来龙去脉在本卷内交代完整。

## 1. 偏重：市井人情 + 因果离合

三言是话本（说书底本）改写的短篇，核心是 **寻常人的悲欢、世态人心、善恶因果**。睡前最适合写：

- 商旅、店铺、码头、客栈、灯市、茶肆这些市井场景
- 钱财、信物、书信、误会、巧合这些推动情节的小事
- 重逢、还报、雪冤、守信、知恩这些温厚的落点

事件密度比三国低一档：一卷讲清一件事的来龙去脉即可，多留一两段景物或人物心境的呼吸。**节奏比悬念重要**——是讲故事，不是说书抖包袱。

## 2. 入话与诗词：删繁，化白话

话本原文卷首常有"入话"（一首诗 + 一段引子小故事铺垫主题）。睡前版处理：

- 卷首长篇议论、劝世诗 → **压成两三句温和的开场白**，点出本卷的味道即可，不照搬
- 正文里的诗、词、judgment 句 → 一句白话转述："他提笔写了首诗，大意是说……"
- 不出现"看官听说""话分两头""且听下回"这类说书套语（极少量"却说"调味可留）

## 3. 主要人物首次画像（各卷人物不同，给"一笔可见"的画法示范）

短篇人物每卷换一批，没有固定花名册。首次出场统一给 **一笔具象画面**（身量／面容／衣着／神气／嗓音取其一二），再次出现只用名字。示范笔法：

| 类型 | 一笔画面示范 |
|---|---|
| 年轻商人 | 二十出头，面皮白净，穿一领半新不旧的绸衫，说话和气。 |
| 持家少妇 | 鬓发齐整，眉眼温婉，手上总有做不完的针线。 |
| 老成长者 | 须发花白，背微驼，说话慢，眼里有阅过世事的平和。 |
| 市井牙婆 | 一张能说会道的嘴，眼珠子滴溜溜转，笑里带三分算计。 |
| 落魄书生 | 身形清瘦，衣衫旧了，眉宇间一股不肯低头的气。 |
| 江湖侠客 | 身量壮实，眼神沉稳，腰间不离一物，话不多。 |

牙婆、媒人、势利人这类反派也只给一笔，不丑化到狰狞，点到"算计""贪利"为止。

## 4. 男女私情：一笔带过，只留情味不留露骨

三言不少卷涉及私情、偷期、烟花（如珍珠衫、新桥市、金玉奴等）。严守三国 §3 的"一笔带过"，移到情爱上：

- 只写"动了心""背了夫""一来二去熟了""那夜便没回家"这种轻笔，**绝不写身体、不写床笫、不写挑逗细节**
- 烟花女、私通这些只交代关系与后果，给读者"知道发生了什么"即可
- 重点永远落在 **后续的因果与人心**（悔、报、谅、聚），不在情事本身

## 5. 小道具（每卷至少一处可触可感的物件）

三言最动人的是一件信物牵动整个故事。每卷至少认真写一处 **能闻能摸的器物**，并让它在情节里"管事"：

- 一件缝着珍珠的纱衫
- 一支断了股的金钗
- 一封字迹潦草的家书
- 一只随身多年的旧荷包
- 一盏灯市上买的走马灯

一处足矣，写得让人记住它，后面好让它回扣。

## 6. 冲突与公案：点到为止

三言多有公案、争产、报冤的卷（如陈御史、滕大尹、宋四公）。冲突、刑讯、争斗 **一律轻笔**：

- "县官升堂问了几句，事情的真相便一层层翻了出来。"
- 用计、断案写"机关"和"转折"，不写打骂、不写血、不写痛苦
- 死亡（害命、自尽、病故）按情节交代，写成"安静的离开"，不渲染惨状

## 7. 称呼与年代感

- 人物互称按宋元明市井习惯：相公、官人、娘子、大姐、妈妈（牙婆／老妇）、员外、店家
- 生僻人名地名首次出现注拼音：`卖䭔媪（mài duī ǎo）`、`阮三（ruǎn sān）`，常见字（蒋兴哥、王三巧）不注
- 货币、度量用原味白话："二十两银子""一匹绸""三百贯"，不换算现代单位

## 8. 收尾意象池（喻世明言专用，禁跨卷复用整段）

按三国 §7 严格执行：结尾整段散文每卷都要不同，QA 跨卷 diff 倒数 150 字。本系列可取的安静落点：

- 客船解缆，灯影顺水退远
- 灯市散后，一地踩碎的花灯纸
- 重逢的两人相对无言，茶在手里凉了
- 旧信物收进箱底，盖子轻轻合上
- 码头上一盏渐远的船灯
- 庭中那株树又开了花，人事已换
- 一封迟到多年的家书终于送达，读信人久久没动
- 雪落在屋檐，炉火噼啪，一家人重新围坐

## 9. 整体走向（四十卷皆独立，无总纲）

四十卷各自成篇，无连续主线，故不设"前期／后期"。每卷自给自足：**开场点味 → 起因（人物＋一件信物／一桩事）→ 离合波折（私情／公案／信义，皆轻笔）→ 因果落定 → 一个本卷独有的安静收尾**。卷与卷之间唯一要守的连续性是 **声音与节奏的一致**：同一个床头长辈，四十夜讲四十个不相干的故事，口吻始终如一。

## 10. 参考样本

第 1 卷 `001.json`《蒋兴哥重会珍珠衫》是参照样本：商旅别离的节奏、珍珠衫这件信物如何贯穿、私情如何一笔带过、最后破镜重圆的温厚落点。新写的卷应当能跟它在视角、语速、安抚 cue 上无缝拼接。
