# 二刻拍案惊奇白话睡前版 · 写作规范

四十卷（尚友堂刊本）。整体规范跟三国/红楼系列一致（先读 `presets/sanguo/STYLE.md`：篇幅、视角、战斗一笔带过、章末安抚 cue、不允许内容、文件格式都照搬），本文只列**二刻拍案惊奇特有**的差别。

## 0. 这是什么书

凌濛初编的拟话本短篇集，「二拍」之二，跟「三言」（喻世/警世/醒世）同一脉。**四十卷彼此独立，没有主线，没有连贯人物**——每卷是一个自成因果的市井故事。题材多为：商贾买卖、婚恋离合、公案断狱、奸情报应、僧道因果、科场宦海。背景多在明代（少数托宋元）。

⚠️ 因为每卷独立，**不存在「跨章人物连续性」**。但「跨章不复用收尾段落 / 不复用开篇套路」这条红线反而更要紧——四十个独立故事最容易写成同一个模子。

## 1. 入话（头回）的处理

原著每卷是「入话（头回小故事）＋ 正话（主故事）」双层结构，篇首篇末还有诗词、「看官听说」的议论。睡前版**只讲正话**：

- 入话压成**一两句引子**，或干脆删掉直接进正话；不要把头回当独立故事讲，否则一回里塞两个故事，节奏全乱
- 篇首/篇末诗词、「有诗为证」、酒令灯谜 → 全删，或化成叙述者一句话的心情/画面
- 「看官」「说话的」「话分两头」「且听下回」这类话本套语：可极少量保留做调味（一回最多一次），其余去掉

## 2. 诗词与议论改白话

同红楼 §2：原文里的诗、词、判、对联、书信里的骈句，一律改成两三句现代白话，**不照搬一句原文**。凌濛初爱在结尾发一通因果劝善议论——压成叙述者淡淡一句即可，不说教。

## 3. 人物首次画像（按"类型"给笔法，不是固定人物）

每卷人物全不同，所以不列固定人物表，列**常见角色类型的画法**。第一次出场给一笔具象画面，再次出现只用名字：

| 类型 | 一笔画面示例 |
|---|---|
| 书生 / 秀才 | 一袭半旧青衫，面白，说话斯文，袖口磨得起了毛。 |
| 商人 / 客商 | 精神结实，腰里一个鼓鼓的搭膊，眼睛会算账。 |
| 少妇 / 闺秀 | 鬓边一支银簪，低着头，手指绞着帕子。 |
| 老者 / 员外 | 须发花白，拢着袖子，慢声慢气。 |
| 僧 / 道 | 一身缁衣或道袍，眉目或清冷或藏着算计。 |
| 衙吏 / 公人 | 腰牌一晃，眼神滑，话里有钩。 |
| 侠女 / 烈妇 | 眉眼里有股不肯低头的劲。 |

画一笔就够，别堆形容词。市井人物重在**神态和小动作**，不在容貌。

## 4. 小道具（市井质感，每回至少一处）

二刻最好看的是**钱、物、契、案**的烟火气。每回至少落一处这种具体物件，让故事有重量：

- 一锭雪花银、一串铜钱、一张当票
- 一纸文契 / 婚书 / 借券，上头的押字
- 一本账簿、一杆戥子、一面酒旗
- 一卷旧经、一枚私印、一只香袋、一副棋枰
- 一碗浊酒、客店墙上的灯

不开清单，**一处写透**比五处带过强。

## 5. 冲突 / 公案 / 奸情 = 一笔带过

二刻里命案、刑讯、奸情、骗局极多。按三国战阵规矩处理：

- 命案：「等人寻来，那人已经倒在血泊里，没了气。」——交代结果，不写伤口、不写挣扎
- 公堂用刑：「打了几十板子，招了。」——不渲染痛苦
- 奸情 / 床笫：**一笔带过**，写到「两人自此有了首尾」就收，绝无露骨描写；涉淫秽的入话直接删
- 骗局 / 设局：写机巧和反转的**节奏**，让听众跟着「噢——原来如此」，不写暴戾细节

## 6. 因果与反转

二刻的魂是**「机巧 + 因果」**：一桩看似走投无路的事，靠一个聪明人的一着、或一段善恶报应，绕回圆满或惩戒。睡前版要保住这个「转」，但：

- 转得**温和**，不靠惊悚悬念钩人（不是评书，不喊「且看」）
- 善有善报、恶有恶报点到为止，不站出来说教
- 重点放在「人怎么把一件难事一点点解开」的过程上，舒缓地讲

## 7. 称呼与时代

- 背景多明代：用「相公」「员外」「娘子」「官人」「朝奉」「孺人」「提控」「茶酒（跑堂）」等明代市井称呼，自然带出时代感
- 银两、科举、当铺、客店、衙门是常见场景，写出制度的日常感即可，不掉书袋
- 生僻字 / 易读错的人名地名第一次出现注拼音（同三国 §8），如「赝（yàn）」「瘞（yì）」「镪（qiǎng）」

## 8. 收尾意象池（每回换，严禁跨集模板）

四十卷各自收尾，按三国 §7 红线：倒数整段散文每集必须不同，QA 会跨集 diff 倒数 150 字。可用意象——

- 当票上的押字在灯下慢慢看不清了
- 客店窗外一盏将尽的灯
- 一锭银子搁回箱底，盖子合上
- 巷口卖夜宵的梆子声远了
- 庭中一棵老树落了几片叶
- 渡口最后一班船摇走了
- 经卷合上，香也燃尽
- 棋枰上一子未落，人已睡去
- 一纸婚书叠好，压在妆奁底
- 雨打着客船的篷，一夜到天明

**每集换一个，且整段收尾散文都要不同**，不光最后一句。

## 9. 篇幅与字数（同硬规则）

- body 硬 2200–3300，目标 2500–2700
- 全角双引号 “ ” 作对话/引文，**绝不用 ASCII 半角引号**（会破坏 JSON）
- 文件名 `NNN.json` 三位补零；已确认章节不动，只往后续写

## 10. 整体走向

无主线。四十卷各写一个独立故事，逐卷按 `_toc.json` 的 originalTitle 推进即可。卷四十（《宋公明闹元宵杂剧》）原是一出杂剧而非话本小说——改写时按其情节叙事化为睡前故事，不保留戏曲科白格式。
