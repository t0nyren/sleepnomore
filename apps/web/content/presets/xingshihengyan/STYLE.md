# 醒世恒言白话睡前版 · 写作规范

四十卷（明天启七年叶敬池刊本，冯梦龙编）。整体规范跟三国/红楼系列一致（看 `presets/sanguo/STYLE.md` 与 `presets/hongloumeng/STYLE.md`），本文只列醒世恒言特有的差别。

> ⚠️ 引号硬规则（本批最容易踩）：`body` 里所有对话、引文一律用**全角双引号 “ ”**（U+201C / U+201D），**绝不用 ASCII 直引号 `"`**。body 本身是 JSON 字符串，ASCII 引号要转义、易破坏解析。不嵌套引号。

## 1. 偏重：一卷一故事，写市井人情

醒世恒言不是一部长篇，是 **四十个各自独立的话本短篇**，多取材宋元明的市井生活。每一卷自成一回 `NNN.json`，人物、地点、年代都不一样，互不连贯。所以——

- **没有贯穿全书的主角**，每回从头交代人物。
- 题材偏 **世情**：买卖、婚嫁、官司、恩义、报应。睡前最适合写的是其中**安稳、有人情味**的部分：
  - 街市的早晨、油担、酒旗、河埠头的船
  - 一家人围着的灯、一碗热汤、一件旧衣
  - 几句厚道的对话，一个守信的承诺
- 原著常有「入话」（开篇先讲一个小故事或一段议论引出正文）。睡前版**省去入话的议论**，可以保留极短一两句引子，直接进正文故事。
- 节奏比情节重要：事件密度压低，多写一两段市井景物或屋内细节。

## 2. 诗词、入话议论全部改成两三句白话

原著每卷开头有诗、中间有词、结尾有「诗云」做评断，还有大段议论。**全部化掉**：

- 开篇定场诗 → 一句话的氛围或道理，或直接略去。
- 卷中人物吟的诗词 → 一段散文交代「他写了几句，意思是……」，不照搬原文。
- 卷末「诗云」「正是」的评断 → 不要。结尾按 §8 写一个安静画面。
- 劝善惩恶的大段议论 → 化进叙述，**不要让叙述者跳出来说教**。

## 3. 人物首次出现的画像（按类型，不固定到人）

醒世恒言每回人物都不同，不能像红楼那样列固定人物表。改为：**每个重要人物第一次出现时，给一笔具象画面**（身材、面容、衣着、声气、一个习惯动作），让听众看得见。常见类型的画法参考：

| 类型 | 第一次出现的一笔画面（举例，不要照抄） |
|---|---|
| 清官 / 县令 | 一身洗得发白的旧官袍，面容清癯，话不多，眼神干净。 |
| 商人 / 员外 | 圆脸，腰间一串钱响，笑起来眼睛眯成一条缝，算盘打得飞快。 |
| 良家少女 | 荆钗布裙，低着头，手指上还有做活计留下的针痕。 |
| 落第书生 | 青衫旧了，袖口磨破，眉间一股不肯低头的气。 |
| 老仆 / 义仆 | 背有点驼，手粗，话少，认死理。 |
| 媒婆 / 牙婆 | 一张油嘴，走路风风火火，袖里揣着帕子，见人先笑。 |
| 市井妇人 | 嗓门亮，手脚麻利，围裙上沾着灶灰。 |

同一回里同一人物只描写一次，再出现直接用名字。

## 4. 善恶与因果的处理

醒世恒言主题就是「醒世」——善有善报、恶有恶报、守信重义。这层**要保留**，但——

- **靠故事自己说**，不靠叙述者下评语。该团圆处团圆，该败落处败落，画面交代到即可。
- 恶人的下场**一笔带过**，不渲染。「那人后来吃了官司，家也败了」足矣，不写行刑、不写惨状。
- 善报写成一个**温暖的落点**：一桩好婚事、一次重逢、一家人重新围到一盏灯下。

## 5. 市井「小道具」（每回至少一处）

醒世恒言的味道在烟火气。每回**至少一处**这种带温度的器物 / 街市细节，但**一处就够**，不要堆列单：

- 一副油担，两只油桶，一杆秤
- 一盏沿街挑出的酒旗
- 河埠头一只系着的小船，船头一盏灯
- 一封用蜡封好的家书
- 一只攒了多年的钱罐
- 一件缝了又缝的旧棉袄
- 客店窗里漏出的一星灯火

写得让人闻得到、看得见。

## 6. 冲突场面（官司 / 打斗 / 灾祸）= 一笔带过

醒世恒言里有公堂、有抢劫、有命案、有灾祸。**点到为止**，跟三国战阵同例：

- 公堂用刑：「升堂问了几句，那人抵赖不过，只得招了。」不写夹棍、不写血。
- 抢劫、凶案：「那一夜出了事，等天亮人们才知道。」交代结果，不写过程。
- 死亡用轻笔：「他没能熬过那个冬天」「她最后那段日子很安静」，**无痛苦细节**。
- 涉及男女之私的卷目（如赫大卿、金海陵一类），**只写到情起情灭的氛围，绝不写露骨细节**，一律一笔带过。

## 7. 市井日常的底色（对应红楼「姐妹日常」）

长篇靠日常调剂，醒世恒言每回也要留**至少一处**安稳的市井日常，让故事有呼吸：

- 卖油郎清早挑担、数铜钱
- 一家人围灯吃晚饭、说几句家常
- 渡口等船、茶坊歇脚、庙会看热闹
- 老仆默默把事做周全
- 守信的人为一句承诺奔波

不要只写「事件」，要写一处「过日子」。

## 8. 收尾意象（醒世恒言池 · 市井向）

每回结尾留一个**安静的画面**做入睡落点，**锚在本回出现过的人 / 地 / 物**上，句式每回都要变，**严禁跨回复用收尾整段**（QA 会跨回 diff 倒数 150 字）。可选意象池：

- 街市渐渐静下来，一盏酒旗在风里轻轻摆
- 河埠头的船灯，随水一晃一晃
- 油担歇在墙根，秤杆斜斜靠着
- 一封家书摆在桌上，灯花结了又落
- 巷口的更声远了
- 渡口最后一班船过去，水面合拢
- 灶里的火慢慢暗下去，留一点红
- 客店窗纸上的人影，灯一吹就没了
- 庙会散了，地上落着几片纸花
- 钱罐又添了一枚，盖好放回原处

⚠️ 不准跨回模板段落，整段散文都要每回不同，按三国 §7 严格执行。

## 9. 字符、拼音、数字

- 纯简体中文 + 中文标点；不出现拉丁字符、阿拉伯数字（章序号在元数据里，不在 body）。
- 数字写汉字：「三两银子」「四十卷」「十五贯」。
- 生僻字、易读错的人名地名第一次出现注拼音：`赫大卿（hè dà qīng）`、`徼灵（jiǎo líng）`、`汧公（qiān gōng）`；常见字不注。
- 不出现 emoji、markdown、翻译腔、现代俚语、自我修正、元注释。

## 10. 文件格式与字数

- 每回 `NNN.json`（三位补零），必填字段：schemaVersion / seriesId / chapter / title / originalTitle / summary / body / author / createdAt。
- `title`：自起的睡前友好短标题（2–4 字白话），不照搬原回目。例：卷一「孤女得嫁」、卷三「卖油郎」。
- `originalTitle`：从 `_toc.json` 取，验证脚本会比对。
- `summary`：一句话提要，30 字以内，**不剧透结局**，末尾不加句号。
- `body`：2400–3100 字，**目标 2500–2700**；硬限 2200–3300。
- `author`：`Writer3@opus`。`createdAt`：ISO 8601 UTC。
- 校验：`cd apps/web && node scripts/validate-presets.mjs xingshihengyan --fix`（自动补 charCount / estimatedMinutes）。

## 11. 整体走向

四十卷无主线，但题材有几束，便于把握语气：

- **恩义守信类**（卷一两县令、卷二让产、卷十七认舅、卷十八施润泽、卷三五徐老仆）：写厚道与团圆，最适合睡前，可作样本基调。
- **婚恋姻缘类**（卷三卖油郎、卷七钱秀才、卷八乔太守、卷九陈多寿）：写市井男女的情与缘，温情收束。
- **奇遇神异类**（卷四灌园叟、卷六天狐、卷二二吕洞宾、卷二六薛录事、卷三七杜子春）：保留「远远看、像梦一样」的距离感，只写画面不写术语。
- **公案冤情类**（卷二十张廷秀、卷二七李玉英、卷三三十五贯、卷三四一文钱、卷三六蔡瑞虹）：冤屈与昭雪，公堂一笔带过，落点放在沉冤得雪后的安稳。
- **情欲讽世类**（卷十五赫大卿、卷二三金海陵、卷二四隋炀帝）：只写氛围与因果，露骨细节全部略去，一笔带过。

每回大体：一个市井情节单元 + 至少一处过日子的日常画面 + 一段街市 / 屋内细节，结尾一个锚在本回的安静落点。

## 12. 参考样本

第 1 回 `001.json`《两县令竞义婚孤女》是参照样本。开篇人物登场、市井场景、恩义底色、结尾锚在本回的安静画面——这些是基准。新写的回目应当能跟它在节奏、视角、安抚 cue 上无缝拼接。
