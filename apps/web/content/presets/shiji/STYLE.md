# 史记白话睡前版 · 写作规范

七十集选篇（一三〇篇里取主要本纪 + 世家 + 列传）。整体规范跟三国/醒世恒言系列一致（先读 `presets/sanguo/STYLE.md`：篇幅、视角、战斗一笔带过、章末安抚 cue、不允许内容、字符与拼音、文件格式都照搬），本文只列**史记特有**的差别。

## 0. 这是什么书

司马迁的《史记》，纪传体通史，二十四史之首。**不是小说，是史传**——但我们要做的是「睡前听的史记」：保住史家叙事的筋骨（人物、功业、命运、史公的褒贬），却用今人舒缓的白话节奏讲出来，去掉一切让人睡不着的东西（战阵、血腥、酷刑、权斗的肃杀）。

⚠️ 选篇彼此独立，没有连贯主角，但有一条**隐约的时间长河**：从五帝、夏商周，到春秋战国诸子百家、四公子纵横，再到秦汉之际的项羽刘邦，最后落到汉武一朝与太史公自序。**跨集不复用收尾段落 / 不复用开篇套路**这条红线照旧最要紧——七十集最怕写成一个模子。

## 1. 基调（最重要）

- **史家叙事 + 今人白话节奏 + 助眠化**。叙述者像一位读了一辈子史书、坐在床头慢慢讲给你听的长者，娓娓道来，不慷慨激昂、不评书抖包袱。
- 保留太史公的「**史识**」：每个人物的命运里那一点可叹、可敬、可惜，淡淡点出（化用「太史公曰」的意思，**压成叙述者一两句**，绝不长篇议论、不照搬原文赞语）。
- 多写人物**安静的瞬间**，少写功业的喧腾：屈原行吟泽畔、张良圯下拾履、孔子陈蔡弦歌、姜尚渭滨垂钓、范蠡泛舟五湖、李广月夜射虎、荆轲易水将别、扁鹊静观气色、周亚夫细柳治军的那份肃静。功业、战争、结局，都往**克制、收束、一笔带过**里写。
- 节奏：句号优于逗号，多用短句，多留白。一段一个画面或一层意思。

## 2. 选篇与拆 / 合规则

- 篇目见 `_toc.json`，共七十集，已拟订 chapter # 与 originalTitle、summary。
- **拆**：原篇过长、事件多的，拆 2–3 集，originalTitle 加（上）（下）或（一）（二）（三）标记。已拆的有：周本纪(上下)、孔子世家(上下)、越王勾践世家(上下/范蠡)、廉颇蔺相如列传(上下)、刺客列传(上下/荆轲)、秦始皇本纪(上下)、项羽本纪(三集)、高祖本纪(上下)、淮阴侯列传(上下)。
- **合**：原篇过短的，多人合为一集（如管晏、老子韩非、孙子吴起、郦生陆贸、季布栾布、樊郦滕灌——按原合传走）。一集若含两三个人物，**用一条线索或一种品格串起来**（如「知交」串管鲍、「让」串伯夷太伯），不要写成生硬的小传拼盘。
- 每集 body 仍硬 2200–3300、目标 **2500–2700**（同三国硬规则）。拆合都以「凑够一集舒缓的篇幅、又不硬塞」为准。

## 3. 人物首次画像（核心人物笔法）

第一次出场给一笔具象画面，再次出现只用名字。史传人物重在**气度、神态、一个标志性的动作或习惯**，不堆容貌。核心人物建议画法：

| 人物 | 一笔画面示例 |
|---|---|
| 黄帝 / 尧 / 舜 | 上古之君，朴拙厚重，垂衣拱手，话不多而令行。 |
| 大禹 | 面色黧黑，手足生了胼胝，裤腿沾着泥水，多年不曾归家。 |
| 姜太公 | 须发皆白，独坐渭水边，直钩垂在水上，并不为鱼。 |
| 孔子 | 身材高大，温而厉，恭而安；困厄之中仍抚琴而歌。 |
| 老子 | 青牛背上一个淡漠的老者，目光深远，骑出关去，回首一笑。 |
| 屈原 | 形容枯槁，披发行吟在江畔，衣袂沾露，眼里是化不开的忧。 |
| 张良 | 状貌如妇人好女，文弱清秀，却胸藏运筹天下之机。 |
| 项羽 | 身长八尺，力能扛鼎，目有重瞳，一声怒喝，千人皆废。 |
| 刘邦 | 隆准而龙颜，美须髯，性宽大，好酒，待人随和里藏着不动声色。 |
| 韩信 | 身材高大却落魄，腰间一把长剑，受得了胯下之辱的那份沉静。 |
| 李广 | 身形高大，臂长善射，沉默寡言，与士卒同饥渴，不善言辞。 |
| 廉颇 / 蔺相如 | 廉颇赳赳武夫，负气好胜；相如从容文士，临大事而色不变。 |
| 荆轲 | 沉静好读书，爱与人饮于市，醉后或歌或泣，旁若无人。 |
| 范蠡 | 智略深沉，功成之日便换了布衣，扁舟一叶，飘然而去。 |
| 司马迁 | 史官之家，案上简册堆叠，忍着奇耻，一笔一笔写那部书。 |

⚠️ 拼音只在**生僻 / 易错的人名地名**第一次出现时注，例：商鞅（shāng yāng）、范雎（fàn jū）、郦食其（lì yì jī）、冒顿（mò dú）、缇萦（tí yíng）、髡（kūn）。常见字（项羽、刘邦、孔子）不注。

## 4. 战阵 / 血腥 / 酷刑 / 奢淫 = 一笔带过或避开

史记里大战、刑杀、权斗极多。一律按三国战阵规矩从轻处理，**助眠优先**：

- 战争：「巨鹿一战，楚军以一当十，秦军大溃。」——只写气势与结果，不写尸骨、不写斩级数目。
- 酷刑 / 死法：商鞅车裂、李斯腰斩、彭越醢、伍子胥鞭尸、吕后人彘——**避开或一句最轻的话带过**（「后来商鞅也未得善终」即可），绝不描写过程。
- 奢淫：纣王酒池肉林、吕不韦后宫之事、嫪毐之乱——**直接略去或一句点到为戒**，不渲染。
- 权斗的肃杀（夺嫡、诛杀功臣）：写人物的处境与心境，不写血雨腥风；结局从轻收束。
- **政治敏感的**（如削藩、推恩、和亲的是非、后宫嫡庶之争）：避开评判，只取其中可敬可叹的人物侧面（如袁盎之骨鲠不取晁错削藩之争）。已在选篇时尽量回避。

## 5. 诗赋与议论改白话

- 原文的赋、骚、书、铭、对策、辞令（屈原《怀沙》、贾谊《鵩鸟赋》、相如《子虚》《上林》、苏秦张仪的纵横说辞、乐毅《报燕王书》）：**一律化成两三句现代白话转述其意与情，绝不照搬原句**。
- 「太史公曰」的史评：压成叙述者篇末淡淡一句感慨，不说教、不掉书袋。

## 6. 章末安抚 cue 与收尾意象池（古风更厚）

同三国 §7 红线：每集结尾一个**安静的画面**，锚在本集人物 / 地 / 物上；句式与整段散文每集都不同，QA 跨集 diff 倒数 150 字。史记偏古、偏苍茫，收尾意象池可比市井系列更厚重——

- 江水东去，不舍昼夜
- 渭水边一竿空钓，暮色四合
- 泽畔行吟的身影没入芦苇
- 圯上桥头，老人的背影远了
- 残碑断碣上落了薄雪
- 庙堂的青砖，磨得发亮
- 一卷简册在灯下慢慢卷起
- 易水边白衣的人不再回头
- 五湖烟水，一叶扁舟轻轻摇
- 细柳营中刁斗声声，月照旌旗
- 老竹斜倚，史官的笔搁在砚上
- 远山如黛，长河落日

**动静要交替**（接前系列教训）：不要连着几集都是「远去 / 淡入夜色 / 渐渐静下来」。轮换：一处偏亮（灯下卷简）/ 远远响起（刁斗、江声、渔歌）/ 一阵风过（泽畔芦苇）/ 动作收尾（搁笔、合卷、收钓）/ 前瞻一笔（功业留与后人说）/ 对话收尾。给整本留 dynamic range。**慎用「灯 / 月」作主意象**（前系列教训：勿过多），整本严控其出现的集数。

## 7. 称呼与时代质感

- 上古到秦汉，时代跨度大。称谓随朝代走：上古称「帝」；春秋战国称「公」「君」「相」「上卿」「客」「门下」；秦称「王」后称「皇帝」；汉称「天子」「丞相」「太尉」「将军」「郎中」「布衣」。
- 写出制度的日常感即可（分封、客卿、军功、郡县、和亲、举孝廉），不掉书袋、不长篇解释典章。
- 古地名 / 古官名第一次出现时，能用一句话点明今义或方位的就顺带一句（如「圯，就是桥」），帮助听者跟上，但别变成注疏。

## 8. 整体走向与压轴

- 七十集按 `_toc.json` 时间长河顺序推进，每集一个独立完整的人物 / 事件，听完即可入睡，不留悬念钩。
- **卷七十《太史公自序》是压轴**：写司马迁继父之志、忍辱负重、究天人之际而著成此书，**借它收束整部七十集**（如二刻末卷以「安睡感」收束全书的手法），给听者一个温厚的、合上书卷的落点。
