# 三国演义白话睡前版 · 写作规范

这是面向 SleepNoMore（眠安）app 的预设故事内容。读者是临睡前的听众，音频由 TTS 朗读，听者会在故事中段或末尾入睡。所有 120 回必须保持同一种声音、同一种节奏，所以以下规范请严格遵守。

## 1. 篇幅

- **每集 2500–3000 字**（正文 `body` 字段，不计标题/标签）
- 对应 TTS 13–15 分钟语音长度（参考样本 `001.json` 为 2515 字 / 13 分钟）
- 自动校验脚本 `apps/web/scripts/validate-presets.mjs` 设定：
  - **硬下限 2200，硬上限 3300**——超出范围会 fail
  - 软范围 2400–3100——在区间外但未超硬限会 warn

## 2. 视角与口吻

- 第三人称、温和的叙述者
- 像在床头讲故事的长辈，**不是评书**：不抖包袱、不留悬念钩、不喊"且听下回分解"
- 缓慢、留白；句号优于逗号；多用短句
- 文白杂糅 → **全白话**。原著的"却说""话说"这种话本套语可以保留极少量做调味，但不要让叙述变成翻译腔
- 不出现"按下不表""欲知后事如何"这类章回小说套话

## 3. 战斗场面

**一笔带过，永远不渲染血腥。**

- 不写斩首、剖腹、尸横遍野
- 大战可以一句话交代结果："两军在阵前交手不到几个回合，对方便败下阵来。"
- 真要写交手画面，写气势和动作的节奏，不写伤口
- 死亡用"倒下去""不再起来""命陨阵前"这种轻笔，不写血

## 4. 人物登场

- **第一次出场**：给一笔具象画面（身材、面容、动作、嗓音），让听众能看到这个人
  - 例：刘备的大耳朵、关羽的红脸长须、张飞的雷一样的嗓音
- **再次出现**：直接用名字，不重复描写。同一人物在同一集里也只描写一次

## 5. 场景与画面

- 多用画面词：风、云、灯、香、月、桃花、雪、烛影、马蹄、铠甲反光
- 少用排比和形容词堆砌；少用"震天动地""惊天动地""气吞山河"这类大词
- 任何长篇议论、政论、檄文：**改成两三句话的转述**，不要照搬

## 6. 段落

- 每段 1–4 句
- 段与段之间空一行
- 关键转折单独成段，让 TTS 在那里自然停顿
- 对话用引号；不嵌套引号；不出现"道"以外的太多说话动词

## 7. 章末安抚 cue

- 每集结尾留一个**安静的画面**，给听众一个可以入睡的落点
- 句式要变化，**不要每集都用"愿你做一个好梦"**。可以是：
  - 一个远去的背影
  - 一片飘落的花瓣
  - 灯熄了
  - 远处的钟声
  - 一句平淡的祝福
- 收尾不剧透下回；不写"后事如何"；可以淡淡一句"今晚的故事就到这里"

## 8. 字符与拼音

- 纯简体中文 + 中文标点
- 不出现拉丁字符、阿拉伯数字（章序号除外，但章序号在元数据里，不在 body 里）
- 数字写汉字："三""七十万""一百二十回"
- 生僻字、容易读错的人名地名第一次出现时附拼音：`皇甫嵩（huáng fǔ sōng）`、`沮授（jǔ shòu）`、`审配（shěn pèi）`
- 不要在常见字上注拼音（曹操、刘备、诸葛亮不需要）

## 9. 不允许出现的内容

- 外文字符、emoji、markdown 语法（**body 字段是纯文本**）
- 自我修正话术（"刚才说错了""更正一下"）
- 元注释（"作者按""译者注"）
- 翻译腔（"我的天哪""哦，我的朋友"）
- 现代俚语（"卷""躺平""破防"）

## 10. 文件格式

每一回都是 `NNN.json`（三位数零填充），字段如下：

```json
{
  "schemaVersion": 1,
  "seriesId": "sanguo",
  "chapter": 1,
  "title": "桃园三结义",
  "originalTitle": "宴桃园豪杰三结义 斩黄巾英雄首立功",
  "summary": "一句话剧情提要，用于列表页，30 字以内。",
  "body": "完整正文……",
  "author": "tio@opus",
  "createdAt": "2026-06-05T..."
}
```

**必填字段**：上面所有都是必填。

**可选/派生字段**（验证脚本自动计算并写回）：

- `charCount`：`body.length`（含中文标点）
- `estimatedMinutes`：`round(charCount / 200)` —— 按 200 字/分钟的睡前语速估算

写完不用手动填这两个，跑一遍 `node scripts/validate-presets.mjs sanguo --fix` 会自动补上。

**字段说明**：

- `title`：我们自己起的睡前友好短标题（4–8 字），不照搬原回目
- `originalTitle`：原著回目，从 `_toc.json` 取（验证脚本会比对）
- `summary`：列表页展示，30 字以内，**不剧透结局**
- `author`：`tio@opus` 或 `altina@codex`
- `createdAt`：ISO 8601 UTC

## 11. 工作流

1. 在 `apps/web/content/presets/sanguo/` 下直接新建 `NNN.json`
2. 校验：`cd apps/web && node scripts/validate-presets.mjs sanguo`
3. 直接 commit + push 到 `main`，每 10 集一个 commit，commit 信息 `presets/sanguo: chapters NNN-NNN`
4. 推送后在线程里 ping `@tio` 让我 QA

## 12. 参考样本

第 1 回 `001.json` 是参照样本。开篇节奏、人物登场画面、桃园场景、结尾的"桃花仍在风里飘着"——这些都是基准。新写的回目应当能跟它无缝拼接。
